# MOBONDO — prototype Godot 4.0.5

## Contenu
- Scène 3D générée par script : quartier, route, maisons et marché.
- Personnage contrôlable au clavier et avec boutons tactiles.
- Marche, course, saut et interaction.
- Première mission en trois étapes : marché, habitant, colis.
- Sauvegarde locale de la progression dans `user://mobondo_save.json`.

## Commandes
- Clavier : flèches ou ZQSD/WASD, Maj pour courir, E ou Espace pour ACTION, Espace pour sauter.
- Android : flèches tactiles, COURIR, SAUTER, ACTION.

## État de validation
Cette archive a été vérifiée comme ZIP et les fichiers ont été relus lors de sa génération.
Elle n'a pas été ouverte ni exécutée dans le moteur Godot dans cet environnement.
Aucun APK Android n'est inclus. La compilation APK exige Godot 4, les modèles d'export Android,
Android SDK et Java configurés. Ne pas considérer ce prototype comme une version finale testée.
